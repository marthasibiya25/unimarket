# UniMarket MVP — Design Planning

## 1. Design Goal

UniMarket will use a clean, modern, and student-friendly interface. The design will make it easy for students to browse listings, search for items, view listing details, create listings, and send inquiries.

The design will prioritize simplicity, readability, accessibility, and responsive behavior across desktop, tablet, and mobile devices.

## 2. Color Palette

| Purpose        | Color           | Hex       |
| -------------- | --------------- | --------- |
| Primary        | Deep Blue       | `#1E3A8A` |
| Secondary      | Light Blue      | `#3B82F6` |
| Background     | Very Light Gray | `#F8FAFC` |
| Cards/Surface  | White           | `#FFFFFF` |
| Primary Text   | Dark Gray       | `#1F2937` |
| Secondary Text | Medium Gray     | `#64748B` |
| Success        | Green           | `#16A34A` |
| Error          | Red             | `#DC2626` |

### Color Usage

* Deep Blue will be used for primary buttons, navigation, and important headings.
* Light Blue will be used for links and secondary interactive elements.
* Very Light Gray will be used as the main page background.
* White will be used for cards and content areas.
* Dark Gray will be used for primary text.
* Green will communicate successful actions and available items.
* Red will communicate errors and destructive actions.

## 3. Typography

### Primary Font

**Inter** will be used as the primary font because it provides a clean and readable appearance across different screen sizes.

### Typography Hierarchy

* **H1:** 32–40px, bold
* **H2:** 24–32px, bold
* **H3:** 20–24px, semibold
* **Body:** 16px, regular
* **Supporting text:** 14px, regular
* **Buttons:** 14–16px, semibold

A consistent typography hierarchy will help users understand the importance and relationship of different pieces of information.

## 4. Layout

UniMarket will use a responsive, centered content layout.

### Header

The header will contain:

* UniMarket branding
* Main navigation
* Search access
* Login/profile controls

### Marketplace

The main marketplace will display listings using reusable cards.

Each listing card will contain:

* Item name
* Price
* Category
* Availability
* Short description
* Link or button to view the listing

The number of cards per row will adjust according to screen size.

### Listing Details

The listing details page will display:

* Item name
* Description
* Price
* Category
* Availability
* Seller's public display name
* Inquiry form for authenticated buyers

### Forms

Forms will be used for:

* Registration
* Login
* Profile updates
* Creating listings
* Editing listings
* Sending inquiries

Each form will use clear labels, consistent spacing, validation, and readable error messages.

## 5. Spacing Conventions

UniMarket will use a consistent spacing scale based on multiples of **4px**.

| Element                    | Spacing |
| -------------------------- | ------: |
| Small gaps                 |   4–8px |
| Form field spacing         | 12–16px |
| Card padding               | 16–24px |
| Section spacing            | 32–48px |
| Major sections             | 48–64px |
| Mobile horizontal padding  |    16px |
| Desktop horizontal padding | 24–32px |

Consistent spacing will keep the interface organized and prevent content from appearing crowded.

## 6. Responsive Design

The application will support:

* Mobile phones
* Tablets
* Desktop computers

Listing cards will use fewer columns on smaller screens. Navigation, forms, buttons, and content areas will also adapt to different screen sizes.

## 7. Accessibility

The design will include:

* Sufficient color contrast
* Clearly labelled form controls
* Keyboard-accessible controls
* Visible focus states
* Readable font sizes
* Semantic HTML
* Clear success and error messages
* Responsive layouts

## 8. Reusable Visual Components

The team will maintain consistent styling across reusable components such as:

* Navigation
* Buttons
* Listing cards
* Forms
* Input fields
* Status messages
* Page headings
* Content sections

## 9. Design Summary

The UniMarket MVP will use a blue-based color palette, Inter typography, responsive card-based layouts, and a consistent 4px spacing system. These conventions will provide a consistent and accessible user experience across the marketplace, listing pages, account pages, and inquiry features.
